Clover Hollow Art Prompts

Ready-made prompts for ChatGPT's image tool, so every sprite comes out in the same cozy, hand-painted style. Work top to bottom and tick each one off when you have a picture you love.

How it works

  1. Open ChatGPT and start one new chat just for Clover Hollow art. Keeping everything in one chat keeps the style consistent.
  2. Copy the Style master prompt and send it. Regenerate until you truly love the barn. That picture becomes the style every other sprite copies.
  3. Then copy the prompts below one by one, in the same chat. Each one says "same style as the barn".
  4. If a picture comes back with a background, reply: "Same image, but with a fully transparent background, PNG."
  5. Download each picture and name it like the title on its card, for example sunpea_ripe.png.
  6. Send the files to me (or to Claude Code). I'll trim them, size them and put them into the game.

Check that the art tool lets you use its pictures in your own game. ChatGPT's terms allow this today, but terms can change, so take a quick look before you publish.
